음성 보디캠(voiceBodyCam) 개인정보처리방침

시행일: 2026-10-04

음성 보디캠은 개발자 본인이 일상 음성에서 기억할 내용을 정리하기 위해 만든 개인용 Android 앱입니다. 이 문서는 앱이 어떤 정보를 다루고, 어디로 보내며, 어떻게 지우는지 설명합니다.

1. 앱이 다루는 정보

정보어디에 저장되는가왜 필요한가
마이크 음성(16kHz 모노 WAV)기기 내부 저장소말소리가 끝난 구간을 받아쓰기 위해
받아쓰기 텍스트기기 내부 저장소기억 항목 추출과 일일 정리
추출된 기억 항목(할 일, 약속, 결정, 사람, 아이디어, 주의, 핵심)기기 내부 저장소앱의 기억 인박스
설정값(API 키, 봇 토큰, 임계치 등)기기 내부 저장소앱 동작
동작 로그(정리 결과, 오류, 청취 시작/중지 시각)기기 내부 저장소장애 분석

앱은 광고 식별자, 위치, 연락처, 계정 비밀번호를 수집하지 않습니다. 개발자 서버는 없습니다.

2. 외부로 보내는 정보

받는 곳보내는 것조건
Groq (api.groq.com)음성 파일, 받아쓰기 텍스트사용자가 설정에 입력한 본인의 Groq API 키로 받아쓰기와 요약을 요청할 때
Telegram Bot API (api.telegram.org)일일 정리 텍스트사용자가 「일일 정리를 텔레그램으로 보내기」를 켠 경우에만
Google Drive (googleapis.com)AAC로 변환한 음성 파일, (선택) 받아쓰기 텍스트사용자가 「삭제 전에 녹음 원본을 Google Drive에 올리기」를 켜고 Google 계정으로 동의한 경우에만

각 서비스의 처리 방식은 해당 서비스의 약관과 개인정보처리방침을 따릅니다.

3. Google 사용자 데이터

앱은 Google Drive API의 https://www.googleapis.com/auth/drive.file 범위만 요청합니다. 이 범위로는 앱이 직접 만든 파일과 폴더만 보고 쓸 수 있으며, 사용자의 다른 Drive 파일에는 접근할 수 없습니다.

  • 사용 목적: 녹음 원본을 사용자의 Drive 음성 보디캠/날짜/ 폴더에 보관한 뒤 기기에서 지우기 위해서입니다.
  • 저장: 액세스 토큰은 저장하지 않고 필요할 때마다 Google Play 서비스에서 받습니다.
  • 공유: Google에서 받은 정보를 제3자에게 전달하거나 판매하지 않으며, 광고에 쓰지 않습니다.
  • 앱의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 포함하여 그 정책을 따릅니다.

접근 권한은 언제든 Google 계정 → 보안 → 타사 앱 및 서비스에서 철회할 수 있습니다.

4. 보관과 삭제

  • 기기의 음성 원본은 일일 정리가 전송된 뒤 지웁니다. Drive 보관을 켠 경우에는 Drive에 올라간 파일의 체크섬이 확인된 뒤에만 지우며, 14일 넘게 올리지 못한 파일은 기기 용량을 위해 지웁니다.
  • 받아쓰기 텍스트와 기억 항목은 기기에 남습니다. 오래된 항목은 자동으로 보관 상태가 되고 30일 뒤 지워집니다.
  • Drive에 올라간 파일은 사용자의 Drive에 남으며, 사용자가 Drive에서 직접 지웁니다.
  • 앱을 삭제하면 기기 안의 모든 데이터가 함께 삭제됩니다.

5. 제3자 녹음에 관한 안내

주변 대화 녹음은 국가와 상황에 따라 상대방의 동의가 필요할 수 있습니다. 앱 사용자는 관련 법령을 지킬 책임이 있습니다.

6. 아동

이 앱은 만 14세 미만을 대상으로 하지 않습니다.
